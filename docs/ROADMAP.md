# AHI Roadmap

## V4 — Public information launch
- resilient MCP collector with retry/backoff
- no partial snapshots
- append-only evidence ledger
- SHA-256 artifact digests
- Merkle checkpoints
- optional Ed25519 checkpoint signing
- richer compare output, including generic content drift
- public status export generated from real stored data
- public site explains historical/evidence capabilities
- no hard-coded production passwords or payment secrets

## V4.1 — Identity and normalization
- persistent AHI IDs for agents/entities
- canonical aliases and developer/owner relationships
- license/status/protocol normalization
- evidence links per field
- migration of MCP snapshot data into normalized entities

## V4.2 — Capability and risk drift
- capability/permission drift
- license/pricing/governance drift
- incident + vulnerability timelines
- protocol/version compatibility history

## V4.3 — Market intelligence
- sourced public adoption metrics
- reported vs observed labels
- package/download/repository signals
- cost model and standardized workload definitions

## V4.4 — Verification network
- versioned benchmark specifications
- automated verification nodes
- latency distributions and task success/failure metrics
- signed test results
- external checkpoint anchoring

## Commercial layer
- real authentication
- Free / Pro / Business entitlements
- payment provider links/checkout
- alerts, exports, API keys, quotas
- enterprise evidence and historical reports
