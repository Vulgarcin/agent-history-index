# AHI V11 Release Candidate

This build consolidates the launch-feedback cycle on top of V10 security hardening.

Key changes:
- Signals + Evidence + Methodology merged into Intelligence & Evidence.
- Compact Free/Pro feature navigation while preserving readable typography.
- Duplicate Market Signals panel removed from Directory.
- Market Terminal now consumes real daily comparison data generated locally.
- Activity and Growth are AHI-defined historical change indices, not financial prices.
- Top ranking is selectable; selected series is neon green, peers are muted.
- Real min/max values and dates are shown for the selected series.
- Downloads and Rating remain explicitly source-pending instead of fabricated.
- Demo Pro connects History, Drift, Market, Evidence/Merkle, T0/T1 and export to available historical data.
- Benchmarks, active SLA probes and CVE feeds remain explicitly pending.
- Sponsor placeholders reserve future premium advertising inventory.
- Lightweight cyber/digital-rain intro is shown once per browser session.
- Security controls from V10 remain in place.
