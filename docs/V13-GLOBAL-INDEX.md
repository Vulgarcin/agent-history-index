# AHI V13 — Global Index Free

## Direction
AHI is fully free in this phase. The goal is to build a useful global AI index now and accumulate historical intelligence before any future monetization.

## What changed
- MCP remains a major technical category but no longer defines the whole product.
- Added `data/entities/ai/` with source-attributed anchor entities across AI products, tools, agents, model families and frameworks.
- Directory pages are entity-centric and avoid repeating the same facts across multiple cards.
- Entity tabs are: Summary, History, Capabilities, Security, Evidence.
- Global ecosystem numbers stay outside individual entity tabs.
- Historical output is also written as `history.json`; `pro.json` remains temporarily for backward compatibility only.
- Market only includes entities after real AHI observations or attributed external measurements exist.
- No client-side Pro/demo/paywall UI remains.

## Seed semantics
Curated seed files are discovery records, not fake historical observations. A seed can identify a product and its official source before AHI has enough historical measurements. Unknown fields stay null/empty until enrichment.
