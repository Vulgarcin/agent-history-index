# AHI Web v4

Static public information layer for the first AHI launch.

## Production-safe decisions in this version
- no hard-coded demo password
- no fake payment processing
- no private keys or API secrets in browser code
- public status is generated by the collector pipeline into `web/data/status.json`
- Pro is presented as upcoming until real authentication/payment entitlements exist

## Preview
```bash
cd web
python -m http.server 8000
```
Open `http://localhost:8000`.

The public front-end should remain separable from private collectors, premium datasets,
signing keys, verification nodes, and privileged APIs.
